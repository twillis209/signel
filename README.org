* Signel
[[https://www.gnu.org/licenses/gpl-3.0][file:https://img.shields.io/badge/License-GPLv3-blue.svg]] [[https://melpa.org/#/signel][file:https://melpa.org/packages/signel-badge.svg]]

Signel is an Emacs interface for [[https://signal.org][Signal]]. It communicates with a running
~signal-cli~ daemon via JSON-RPC to send and receive messages.

This is a fork of [[https://github.com/keenban/signel][keenban/signel]] with security hardening: [[https://github.com/twillis209/signel][https://github.com/twillis209/signel]].

** Features

- *Chat Buffers*: Read-only history with a guarded input prompt.
- *Images*: Images from known contacts show inline; others show a ~[Show image]~ button. PNG, JPEG, GIF and WebP are detected from file contents.
- *Animated Stickers*: Automatically converts APNG and WebP stickers to GIF for playback in Emacs. Animation stops after ~signel-animation-max-time~ seconds.
- *Attachments*: Received files show their real extension; opening one asks for confirmation (and is quarantined on macOS).
- *Sending images*: Paste an image or attach any file; images are stripped of metadata before sending.
- *Dashboard*: Overview of active conversations.
- *Notifications*: Native macOS notifications (via ~osascript~) or D-Bus notifications on Linux.

** Dependencies

1. *Emacs 27.1+*
2. *[[https://github.com/AsamK/signal-cli][signal-cli]]*: Must be installed and available in your ~$PATH~.
3. *ImageMagick* (Optional): ~convert~ renders animated stickers; ~magick~ or ~convert~ strips metadata from sent images and converts HEIC to JPEG.
4. *Clipboard tool* (Optional): ~pngpaste~ (macOS), ~wl-paste~ (Wayland) or ~xclip~ (X11), for pasting images. Emacs's own clipboard is tried first.

** Setup

Before running Signel, you must link or register your account using the command line.

*** Example (Linking a new device)

#+begin_src bash
signal-cli link -n "emacs-client" | xargs -n 1 qrencode -t utf8
#+end_src

** Installation
~signel~ is available on [[https://melpa.org][MELPA]].

You can install ~signel~ with the following command.

#+begin_src
M-x package-install RET signel RET
#+end_src

For a basic configuration, place this in your ~user-init-file~

#+begin_src emacs-lisp
(setq signel-account "+15550000000")
#+end_src

*** use-package
#+begin_src emacs-lisp
(use-package signel
  :config
  ;; REQUIRED: Your registered phone number
  (setq signel-account "+15550000000")

  ;; Optional: If signal-cli is not in your $PATH
  ;; (setq signel-cli-program "/usr/local/bin/signal-cli")
)
#+end_src

** Usage

- Start the background process:
  ~M-x signel-start~

- Open the conversation list:
  ~M-x signel-dashboard~

- Open a specific chat directly:
  ~M-x signel-chat~ (complete on contact or group name, or type a +number)

- Re-read the contact list from your phone (contacts show their saved names):
  ~M-x signel-refresh-contacts~

*** Names and images

Contacts with a saved name (and not blocked) are shown under that name. Other senders show their profile name and number. Group chats always show numbers. Sent messages show "(sending…)" until signal-cli confirms, and partial group failures are listed.

*** Sending images and files

In a chat, ~C-y~ (evil ~p~/~P~, or Cmd-V) queues an image from the clipboard instead of pasting text. Text pastes as before, and evil named registers are untouched. ~C-c C-a~ queues any file.

Queued items appear above the prompt with the recipient's name. ~C-c C-k~ removes the last one; ~C-u C-c C-k~ removes all. Type an optional caption and press ~RET~ to send everything as one message. If a send fails, the items and caption come back.

Metadata (location, camera data) is stripped from images with ImageMagick (~magick~ or ~convert~). HEIC is converted to JPEG; GIFs and non-image files are sent unchanged. If an image could not be cleaned it is marked, and ~RET~ asks before sending. Files over ~signel-max-attachment-size~ (default 100 MB) are refused.

*** Customisation

| Option                       | Default   | Purpose                                                              |
|------------------------------|-----------|----------------------------------------------------------------------|
| ~signel-auto-display-images~ | ~t~       | Show known contacts' images inline; if nil, always use buttons       |
| ~signel-animation-max-time~  | ~15~      | Seconds an animated image or sticker keeps animating                 |
| ~signel-log-message-bodies~  | ~nil~     | Log full message JSON to ~*signel-log*~                              |
| ~signel-max-line-length~     | ~5000000~ | Longest line of signal-cli output accepted; longer lines are dropped |
| ~signel-contacts-timeout~    | ~5~       | Seconds to hold incoming messages while waiting for contacts         |
| ~signel-max-attachment-size~ | ~104857600~ | Largest outgoing attachment, in bytes                              |

For example:

#+begin_src emacs-lisp
(setq signel-animation-max-time 5
      signel-auto-display-images nil)
#+end_src

*** Keybindings

**** In Chat Buffers

| Key                | Command                 | Action                                  |
|--------------------+-------------------------+-----------------------------------------|
| ~RET~              | ~signel-send-input~     | Send message and queued items           |
| ~C-c C-c~          | ~signel-send-input~     | Send message and queued items           |
| ~C-c C-a~          | ~signel-attach-file~    | Queue a file                            |
| ~C-c C-k~          | ~signel-remove-pending~ | Remove last queued item (~C-u~: all)    |
| ~C-y~, ~p~, ~P~    | ~signel-paste~           | Queue clipboard image, else paste text  |

**** In Dashboard

| Key   | Command                       | Action             |
|-------+-------------------------------+--------------------|
| ~RET~ | ~signel-dashboard-open-entry~ | Open selected chat |
| ~n~   | ~forward-button~              | Next chat          |
| ~p~   | ~backward-button~             | Previous chat      |
| ~g~   | ~signel-dashboard-refresh~    | Refresh list       |
